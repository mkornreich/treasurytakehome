        How to use Label Check

        1. Add a picture of the label. You can use a scan or a photograph. An angle or glare in the picture is permitted.
        2. Type the data from the application. To skip an item, leave its box empty.
        3. Click “Check label”. The results usually come in 1 to 5 seconds.

        What the results mean

        • ✓ OK The label shows the same data as the application.
        • ! Examine The tool is not sure. For example, the text is hard to read, or it is almost the same. Examine the label yourself.
        • ✕ Problem The tool found a conflict. For example, the label shows a different number, or the warning text is not word-for-word.

        Click “Show on the label” to see where the tool found an item. Click a picture to see it larger.

        What the tool compares

        • Brand name, class or type, bottler, and country of origin. Differences in capital letters and punctuation are permitted, for example “STONE'S THROW” and “Stone's Throw”. If the text is almost the same, the result is Examine.
        • Alcohol content and net contents. The tool compares the values. Thus “750 mL” is the same as “75 cl”, and “12 FL. OZ.” is the same as “355 mL”. The proof must be two times the ABV.
        • Government warning. The text must be word-for-word. “GOVERNMENT WARNING:” must be in capital letters and in bold type (27 CFR 16.21 to 16.22).

        About the tool

        • The tool gives advice. A compliance agent must make the decision.
        • The tool does not keep the pictures or the application data. When the check is completed, the tool erases them.
        • The tool reads the labels in your browser. If the browser cannot confirm all items, the tool sends the pictures to this server, and the server reads them again with more methods.
        • If the server does not answer, the browser does all of the work.
        • The tool does not use outside services. If the network blocks them, the tool continues to operate.
        This is a prototype for evaluation. The results are advice only. A compliance agent must make the final decision. The tool does not keep uploaded files.
